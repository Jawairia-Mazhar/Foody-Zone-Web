<p>✔ Displays the list of food items</p>
<p>✔ Filters food by category: All / Breakfast / Lunch / Dinner </p>
<p>✔ Allows search by food name</p> 
<p>✔ Shows loading and error UI when needed</p>
<p>✔ Uses styled-components for styling</p>
